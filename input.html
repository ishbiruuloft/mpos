Cara Pakai

Halaman ini dan halaman pedigree sudah terhubung otomatis: begitu data disimpan di sini, klik Lihat Pedigree dan silsilahnya langsung memakai data terbaru. Langkah di bawah hanya diperlukan bila Anda ingin data tersimpan permanen ke berkas Excel.

  1. Isi formulir lalu klik Simpan Merpati. Ulangi untuk setiap merpati, termasuk induk dan kakek-neneknya.
  2. Klik Lihat Pedigree untuk memeriksa hasilnya. Silsilah tersusun otomatis dari kolom Dam dan Sire.
  3. Klik Unduh Excel, lalu pindahkan berkas hasil unduhan ke folder ini menggantikan test pedigree.xlsx.
  4. Klik Unduh Semua Foto, lalu pindahkan semua gambar ke folder Gambar Mpos. Nama berkasnya sudah otomatis sesuai nomor ring.
  5. Jalankan ./update-pedigree.sh di Terminal agar pedigree.html ditulis ulang secara permanen dari Excel dan folder foto.
⚠️ Kenapa tidak langsung menyimpan ke Excel? Demi keamanan, halaman web tidak diizinkan menulis ke berkas di komputer Anda — itu berlaku di semua peramban. Karena itu data disimpan dulu di dalam peramban, dan berkas Excel dihasilkan lewat tombol unduh. Selama belum dijalankan langkah 3–5, data hanya ada di peramban ini: jangan bersihkan riwayat peramban, dan salin ke Excel bila datanya penting.
